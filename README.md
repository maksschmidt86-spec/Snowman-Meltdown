# 🎮 Snowman Meltdown ❄️

Ein klassisches Wort-Ratespiel, programmiert mit Python. Errate das geheime Wort, bevor der Schneemann vollständig geschmolzen ist!

## ✨ Features

- **Dynamische ASCII-Art:** Der Schneemann schmilzt Schritt für Schritt bei jedem falschen Buchstaben.
- **Input Validation:** Das Spiel akzeptiert nur gültige Eingaben (einzelne Buchstaben).
- **Replay-Option:** Spiele so viele Runden, wie du möchtest, ohne das Programm neu zu starten.
- **Modularer Code:** Sauberer, PEP-8-konformer Code, aufgeteilt in logische Dateien.
